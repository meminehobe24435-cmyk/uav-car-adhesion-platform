# PS2 按键直行与三挡调速诊断版

## 用途

本固件只验证最短控制链：

`PS2 -> CH559 -> UART5 -> STM32 -> car_forward()/car_stop()`

不读取摇杆，不执行转向测试，不使用飞控、编码器、PID 或 FreeRTOS。

## 按键

- 按一次 `L1`：锁存直行。
- 按 `R1`：立即停止并清除直行锁存。
- 每按一次 `L2`：速度在10%、20%、30%之间循环切换；长按只切换一次。
- 上电默认第二挡20%，挡位顺序为20% → 30% → 10% → 20%。
- 超过 500 ms 没有收到有效的 CH559 x01 数据帧：立即停止。
- 上电默认停止，四个舵机只回中一次。

这是故障定位固件，不是正式遥控固件。L1 采用锁存方式，所以只能在四轮完全架空时测试，并确保随时可以按 R1 或切断底板电源。

## COMTool 观察

USART2 使用 115200、8N1。每 200 ms 输出一次：

```text
PS2=CONNECTED BUTTONS=0x01 RUN=1 GEAR=2 SPEED=20% PWM=20 CMD=FORWARD
```

判断方法：

- 按 L1 后出现 `BUTTONS=0x01`、`RUN=1`、`CMD=FORWARD`：按键和软件命令链已通。
- 按 R1 后出现 `BUTTONS=0x02`、`RUN=0`、`CMD=STOP`：停止命令有效。
- 按 L2 时应短暂出现 `BUTTONS=0x04`，并且每次按下只改变一个 `GEAR`。
- 显示 `RUN=1` 但电机仍不转：问题位于电机供电、TB6612 STBY、PWM/方向输出或机械负载，不是PS2按键映射。
- 一直显示 `PS2=DISCONNECTED`：检查 USB 接收器、CH559、UART5 接收与烧录固件是否正确。

## 第一次测试

1. 四个车轮完全架空。
2. 烧录本目录 Keil 工程生成的固件。
3. 小车上电，确认电机不转、舵机回中。
4. 打开 USART2 调试串口，确认出现 `PS2 BUTTON TEST READY`。
5. 按一下 L1，观察串口 `RUN=1 CMD=FORWARD`，并检查四轮是否低速前进。
6. 短按L2，依次确认挡位从2挡20%切到3挡30%、1挡10%、2挡20%。
7. 按 R1，确认四轮立即停止且串口显示 `RUN=0 CMD=STOP`。
8. 再按 L1 启动后关闭手柄或拔出 USB 接收器，确认 500 ms 左右停车。
