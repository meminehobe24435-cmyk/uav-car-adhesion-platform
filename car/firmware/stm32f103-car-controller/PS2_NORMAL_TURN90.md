# PS2 普通转向 90 度版本

## 当前功能

- 已彻底取消 CRAB 蟹行模式。
- SELECT 当前不使用。
- X 调用 `car_turn(+90.0F, speed)`，执行普通四轮左转。
- B 调用 `car_turn(-90.0F, speed)`，执行普通四轮右转。
- 普通转向仍保持前轴与后轴转角相反。
- X/B 均跟随 L2 当前挡位：30%、60%或80%，没有额外挡位限制。
- L1、A/Y、R1、L2、START和500ms失联保护保持不变。

## 舵机幅度

四路舵机参数统一为：

```text
center_us = 1500
min_us    = 1300
max_us    = 1700
direction = 保持原值
```

`servo_set_angle(+90)` 输出到该舵机的正方向安全端点，`servo_set_angle(-90)` 输出到负方向安全端点。所有输出仍经过 `servo_set_us()` 限幅。

## 第一次架空测试

1. 四个车轮完全架空，挡位保持30%。
2. 上电确认四个电机停止、四个轮子回正。
3. 按X测试普通左转90度；如有机械干涉、异响或舵机持续堵转，立即按R1或断电。
4. 按R1停车，再按START回正。
5. 按B测试普通右转90度；出现异常立即停车或断电。
6. 再次按R1停车并按START回正。
7. 只有确认1300至1700us全行程没有机械干涉后，才测试60%和80%挡位。
8. 运行时关闭手柄或拔掉接收器，确认500ms内停车并回正。

编译通过只代表代码构建成功，不代表90度机械转角已经通过实车验证。
