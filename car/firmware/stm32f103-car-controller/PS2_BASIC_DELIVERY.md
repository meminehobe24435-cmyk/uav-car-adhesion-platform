# PS2基础交付控制

## 最终按键

| 按键 | 功能 |
|---|---|
| L1 | 按一次锁存直行 |
| A | 按一次锁存后退 |
| Y | 按一次锁存后退（第二个后退键） |
| X | 按一次锁存45度左转并前进 |
| B | 按一次锁存45度右转并前进 |
| R1 | 立即停止并取消所有运动锁存 |
| L2 | 20% → 40% → 70% → 20%循环切挡；一次按下只切一挡 |
| START | 立即停车、取消运动锁存并让四个舵机回中 |

所有运动最终只调用现有 `car_forward()`、`car_backward()`、`car_turn()`、`car_stop()` 和 `steering_center()`，PS2层不直接操作GPIO、TIM、PWM或TB6612。

## 安全状态

- 上电默认：STOP、舵机回中、1挡20%、所有运动锁存清零。
- 最大速度：70%。
- 最大转向：正负45度。
- 舵机脉宽安全范围仍保持1400–1600us，没有扩大机械PWM边界。
- 超过500ms未收到有效CH559 x01帧：同一主循环周期内取消运动锁存并执行 `car_stop()`。
- `R1`优先于所有运动和调速命令。
- J4/MOTOR_4继续保持 `direction=-1`，用于修正PA0所在车轮的驱动方向。

## 第一次架空测试

1. 四个车轮完全架空，确认可以随时切断底板电源。
2. 烧录本目录生成的新HEX，小车上电后必须保持STOP、四轮回正，串口显示1挡10%。
3. 按L1一次，四轮以20%车辆前进方向运行；按R1立即停止。
4. 按A一次，四轮以20%车辆后退方向运行；按R1立即停止；Y键执行相同功能。
5. 四轮完全架空并保持1挡20%，按X一次执行45度左转并低速运行；观察机械无干涉后按R1停止。
6. 四轮完全架空并保持1挡20%，按B一次执行45度右转并低速运行；观察机械无干涉后按R1停止。
7. 分别按L2验证2挡40%、3挡70%、1挡20%；长按L2不能连续跳挡。70%只允许在四轮架空并确认方向正确后短时测试。
8. 在任一运动状态按START，确认电机停止并且四个舵机回中。
9. 以20%运行时关闭手柄或拔掉USB接收器，确认500ms内停车。

## 串口判断

USART2调试输出示例：

```text
PS2=CONNECTED BUTTONS=0x00 FACE=3 RUN=1 GEAR=1 SPEED=20% PWM=20 CMD=LEFT
```

其中FACE取值来自厂家已有解析器，并按手柄实际ABXY丝印解释：1=Y、2=A、3=X、4=B。A和Y都调用整车后退接口，不会单独反转某一只车轮。
