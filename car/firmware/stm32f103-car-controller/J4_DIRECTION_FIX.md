# J4驱动电机方向修正

实车确认：PA0舵机所在车轮的驱动电机连接在 `J4 / MOTOR_4`。

本版本只进行以下修改：

```c
MotorConfig motor_config[MOTOR_COUNT] =
{
  { 1, 30U}, /* MOTOR_1 / J1 */
  { 1, 30U}, /* MOTOR_2 / J2 */
  { 1, 30U}, /* MOTOR_3 / J3 */
  {-1, 30U}  /* MOTOR_4 / J4 / PA0所在车轮 */
};
```

`direction=-1`只反转J4驱动电机的车辆坐标正方向，不修改PA0舵机PWM、舵机中位或舵机转向方向。

测试时必须将四轮架空：按L1直行，确认J4与其他三个轮子共同产生车辆前进方向；按R1必须立即停车。
