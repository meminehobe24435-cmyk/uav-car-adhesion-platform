# 四舵机机械零位标定

## 最终实物接口映射

| 舵机 | 位置 | 板上接口 | MCU GPIO | PWM实现 |
|---|---|---|---|---|
| LF | 左前 | J9 | PA0 | TIM5_CH1硬件PWM |
| RF | 右前 | J11 | PA1 | TIM5_CH2硬件PWM |
| LR | 左后 | J12 | PC5 | TIM5统一时基的软件PWM |
| RR | 右后 | J14 | PB0 | TIM5统一时基的软件PWM |

PB5不用于舵机，继续保留为TIM3_CH2编码器输入。

## PWM实现

- TIM5保持72 MHz定时器时钟、PSC=71、ARR=19999。因此计数分辨率为1 us，周期为20 ms（50 Hz）。
- PA0、PA1分别由TIM5_CH1、TIM5_CH2输出硬件PWM。
- PC5、PB0在TIM5更新中断时置高，分别在TIM5_CH3、CH4比较时刻置低。CH3、CH4只作为内部比较时间标记，没有启用PA2、PA3物理输出。
- TIM5中断优先级为5，当前标定程序不启动FreeRTOS，ISR只执行GPIO置位/复位和比较寄存器更新，以降低软件PWM抖动。软件PWM尚未用示波器做定量抖动测量；正式整车联调前建议实测四路周期和高电平宽度。

## 修改center_us和direction

四路参数集中在`bsp/servo.c`顶部的全局数组：

```c
ServoConfig servo_config[SERVO_COUNT] =
{
  {1500U, 1400U, 1600U, 1}, /* LF */
  {1500U, 1400U, 1600U, 1}, /* RF */
  {1500U, 1400U, 1600U, 1}, /* LR */
  {1500U, 1400U, 1600U, 1}  /* RR */
};
```

- 每行第一个数是`center_us`，调整它即可校直对应车轮。
- 第四个数是`direction`，只允许`+1`或`-1`。
- `direction=+1`：正角度增加PWM脉宽。
- `direction=-1`：正角度减小PWM脉宽。
- `servo_set_us()`直接按脉宽控制，不应用direction；direction只由`servo_set_angle()`处理。

## 当前方向标定流程

当前`main.c`默认运行方向标定，而不是旧的脉宽零位标定。上电回正并等待3秒后，按LF、RF、LR、RR顺序逐路执行：

1. center，等待2秒。
2. `servo_set_angle(id, +10.0F)`，等待2秒。
3. center，等待2秒。
4. `servo_set_angle(id, -10.0F)`，等待2秒。
5. center，等待2秒。

测试一路时，另外三路保持各自center_us。观察结果应记录为“+10°实际向车辆左侧/右侧”。若+10°实际向车辆右侧，只把该路`direction`从`+1`改为`-1`，不得在转向上层增加单轮正负特判。

方向确认后可以依次启用：

- `steering_safe_angle_test()`：只循环测试0°、+10°、0°、-10°、0°。
- `steering_safe_angle_20_test()`：仅在±10°实车确认安全后启用，测试0°、+20°、0°、-20°、0°。
- `steering_basic_test()`：循环执行±10°蟹行和前后轴反向的基础四轮转向。

所有转向层输入暂时统一限制在±30°。

## 保留的零位标定流程

旧的`servo_calibration_test()`仍保留但当前不从`main.c`调用。它按LF、RF、LR、RR顺序执行：

1. center，等待1秒。
2. center-50 us，等待1秒。
3. center，等待1秒。
4. center+50 us，等待1秒。
5. center，等待1秒。

测试某一路时，另外三路保持各自center_us。

## 机械中位标定步骤

1. 将车轮悬空或解除地面负载，确认舵机摇臂和连杆不会在1400~1600 us内碰撞机械限位。
2. 先保持四路center_us均为1500，编译并手动烧录。
3. 根据LF、RF、LR、RR依次动作的顺序辨认各轮，重点观察每次回到center时车轮是否机械朝正前方。
4. 对偏斜轮对应的center_us每次只调整5~10 us；重新编译、烧录并观察，直到机械中位合适。
5. 标定center期间保持min_us=1400、max_us=1600，不扩大动作范围。
6. 零位完成后，单独调用正角度进行方向检查。正角度对应期望的车辆转向方向时保持`direction=+1`；相反则改为`-1`。不要在上层算法中交换正负号。

## 安全扩大范围

完成零位和direction检查后，才可以逐路扩大min_us/max_us。建议每次仅向外扩大25~50 us，逐路检查连杆干涉、舵机堵转、异常发热和电源压降。任何异常都应立即断电并退回上一个安全范围。`servo_set_us()`始终把输出限制在该路min_us与max_us之间，`servo_set_angle()`最终也经过相同限幅。

## 资源冲突检查

- 电机PWM定时器未初始化、未启动、未修改。
- TIM3及其他编码器定时器未初始化、未启动、未修改；PB5仍为TIM3_CH2预留。
- 编码器PID、遥控、ROS、飞控通信、自动导航和FreeRTOS均未启动。
- 四舵机仅使用TIM5、PA0、PA1、PC5和PB0，因此当前标定程序不与电机PWM及编码器定时器资源冲突。

本阶段工程只运行四舵机独立控制与机械零位标定；编译过程不会自动烧录。
