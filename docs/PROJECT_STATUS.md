# 项目状态

更新日期：2026-08-17

## 已实测或用户明确确认

- 四个 FT5325M 舵机均可独立驱动；
- 四个舵机执行中心命令后可机械回正；
- PA0/PA1 硬件 PWM 与 PC5/PB0 软件 PWM 已能带动实物舵机；
- 四个 JGA25 减速电机可逐路独立正反转；
- J4 所接电机方向已通过 `MOTOR_4.direction=-1` 修正；
- PS2 无线手柄、USB 接收器、CH559、UART5 到 STM32 的原始数据链路已验证；
- PS2 最小“按键直行/停止”版本曾实车成功；
- USB-TTL 与 STM32 USART2 的收发诊断曾返回 `OK/CRC_ERR`。

## 当前代码已实现并完成构建检查，仍需整车回归

- PS2 L1 直行锁存、A/Y 后退、X/B 普通转向、R1 停止、START 回中；
- L2 30/60/80% 单次按键沿切挡；
- 500 ms PS2 失联停车、回中和锁存清除；
- 普通四轮转向命令 ±90°，同时受 1300~1700 μs 舵机限幅；
- `car`、`motor`、`steering`、`servo` 分层 API；
- USART2 11 字节 CRC8 飞控协议和 DMA 接收模块，但当前未启用车辆输出；
- 编码器 TIM1/TIM3/TIM4/TIM8 资源被保留。

软件中的 ±90° 不能视为机械转角已验证。30/60/80% 当前固件应从车轮架空、30% 挡开始重新回归。

## 飞控侧已收录但待验证

- PX4 `height_commander` 源码、参数和 MicoAir H743-v2/SITL 配置；
- PX4 `mylink_bridge` 实验源码和 FMU-v6x/SITL 配置；
- PX4 上游基线 commit 记录；
- WIT F722 飞控硬件参考 PDF。

本次没有完整 PX4 构建通过日志、最终 `.px4` 固件、SITL 结果或实飞日志。`mylink_bridge` 安全条件不足，禁止实飞启用。

## 未完成

- 飞控—STM32 正式控制权仲裁和状态回传；
- USART2 二进制协议与调试日志分离；
- 自动接近、ToF/触点检测、正压保持、异常脱离；
- 编码器方向/计数实测与 PID；
- 倒挂贴面运动、雷达载荷、续航、温升和结构强度验证；
- CAN 通信、ROS、自动导航和雷达同步。

## 下一步建议

1. 先完成当前 PS2 固件的低挡架空回归和 J1~J4 轮位贴标；
2. 冻结实际飞控型号，保存实物照片和固件目标；
3. 在干净 PX4 基线上完成 SITL 和目标板全量构建；
4. 删除或永久禁用 `mylink_bridge` 的危险直接执行器路径；
5. 实现唯一控制源仲裁，再做 USB-TTL 和真实飞控 UART 台架；
6. 最后进入防护环境中的飞行、压紧和小车集成测试。
