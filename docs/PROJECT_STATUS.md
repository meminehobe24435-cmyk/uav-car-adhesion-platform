# 项目进度总览

更新日期：2026-08-11

## 1. 项目目标

项目采用“多旋翼送达并提供正压、顶部四舵轮小车贴面行走、检测载荷同步工作”的总体路线。第一阶段目标是验证小车控制、飞控控制、贴面压紧、通信和安全状态机；正式样机阶段再根据验证结果收敛结构、载荷、雷达安装和续航指标。

## 2. 四舵轮小车

### 已完成并有代码/记录支持

- 四个 FT5325M 舵机独立控制接口；
- 四舵机机械中位参数集中管理和安全脉宽限幅；
- PA0/PA1 硬件 PWM 与 PC5/PB0 基于 TIM5 的软件 PWM；
- `steering_center()`、`steering_crab()`、`steering_turn()` 基础联动；
- 用户已确认四舵机能够驱动，执行 `servo_center_all()` 后轮子能够机械回正；
- 四路 TB6612 电机 PWM/方向/STBY 底层接口；
- 单电机和依次四电机测试函数，以及直行/后退基础接口；
- 最近留存的 Keil 全量构建记录：0 Error、0 Warning。

### 当前待实测

- J1/J2/J3/J4 分别安装在 LF/RF/LR/RR 的哪一轮；
- 四个直流电机的 `direction` 正负；
- 编码器方向、每圈计数和轮速闭环；
- 四电机同时运行的供电压降、温升和堵转保护；
- 软件 PWM 在后续高负载中断场景下的抖动量化。

### 当前固件运行模式

四舵机保持中位，只有 `MOTOR_1 / J1` 以 20% PWM 做正反转循环。编码器、PID、FreeRTOS 任务、遥控、ROS 和飞控通信未启动。

## 3. 无人机攀附飞控

### 已完成并可从文件确认

- 两阶段样机路线、系统架构、硬件方向和测试阶段规划；
- PX4 `height_commander` 源码、参数和板级启用配置；
- PX4 `mylink_bridge` 串口桥接实验源码及 SITL/FMU-v6x 配置；
- MicoAir H743-v2 作为当前明确的 PX4 板级目标；
- 原目录具有多个 PX4 目标的 CMake 配置痕迹。

### 尚不能宣称完成

- 没有在本次整理中找到最终 PX4 固件或完整通过日志，不能确认当前源树可从零完整编译；
- 没有可复核的 SITL 测试结果，脚本存在不等于测试通过；
- 没有实机解锁、起飞、定高切换、正压贴面或应急脱离证据；
- `mylink_bridge` 仍缺少飞行安全所需的认证、校验、超时、限幅和状态互锁；
- 无人机、小车和检测载荷尚未形成可复核的端到端闭环。

## 4. 推荐下一步

1. 先完成四电机逐路架空测试，确认 J1~J4 的车轮位置和 `direction`。
2. 再启用编码器，只做单轮计数/方向验证，不立即启动四轮 PID。
3. 在干净的 PX4 基线应用覆盖层，分别完成 SITL 和 MicoAir H743-v2 全量构建并保存日志与哈希。
4. 修复并审查 `height_commander` 通道映射、模式切换和人工接管逻辑。
5. 在任何实机测试前重构或禁用 `mylink_bridge` 的直接电机控制路径。
6. 通过台架验证后，再设计无人机—车控通信协议和统一急停状态机。
